# Cursor Rules Directory

This directory contains coding standards and best practices for the Legacy In Order project. These rules are automatically read by Cursor AI to ensure consistent code quality and adherence to project guidelines.

## Rules Files

- **[ui-standards.md](./ui-standards.md)** - UI/UX standards including input styling, component design patterns
- **[testing.md](./testing.md)** - Testing requirements and best practices
- **[architecture.md](./architecture.md)** - Component architecture and reusability guidelines

## How It Works

Cursor automatically includes these rules in the AI context when you're coding, ensuring that:
- All generated code follows your project standards
- Consistent patterns are applied across the codebase
- Best practices are automatically enforced

## Updating Rules

To add or modify rules:
1. Edit the relevant `.md` file in this directory
2. Save your changes
3. Cursor will automatically pick up the updates

## Adding New Rules

To add a new category:
1. Create a new `.md` file in `.cursor/rules/`
2. Document your standards clearly
3. Update this README to reference the new file
