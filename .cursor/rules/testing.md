# Testing Standards

## Testing Requirements

Always write tests when adding or updating functionality.

### Requirements

- ✅ Write unit tests for utility functions
- ✅ Write component tests for UI components
- ✅ Write integration tests for complex workflows
- ✅ Update existing tests when modifying functionality
- ✅ Ensure all tests pass before merging

### Test Coverage

Aim for comprehensive test coverage including:
- Happy path scenarios
- Edge cases
- Error handling
- User interactions
- API integrations

### Testing Tools

Use the appropriate testing tools for the task:
- **Unit Tests**: Jest, Vitest
- **Component Tests**: React Testing Library
- **E2E Tests**: Cypress, Playwright (when applicable)

**Rationale**: Ensures code quality, prevents regressions, and maintains reliability across the application.
